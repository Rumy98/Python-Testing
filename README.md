# Python Testing

A beginner-friendly Python project demonstrating basic automated testing using **pytest**.

## Project Overview

This project contains a simple weather classification function that determines whether the temperature is hot or cold.

The project uses pytest to verify that the function produces the expected results for different temperature values.

## Technologies Used

- Python
- Pytest

## Installation

1. Clone the repository:

```bash
git clone YOUR_REPOSITORY_URL
```

2. Navigate to the project directory:

```bash
cd python-testing
```

3. Install pytest:

```bash
pip install pytest
```

## Running the Tests

Run the following command:

```bash
python -m pytest -v
```
